How an HTTP request enters and is handled. Caddy splits static SPA traffic from the five API prefixes (the Vite dev proxy does the same locally). Inside Hono, a first middleware injects the Db and a clock into context (tests override both), then the path decides: `/health`; `/auth/*` without a session; `/api/*` behind `requireSession`, which puts the user and a `TenantHandle` on the context so routes cannot forget tenancy; `/confirm/:token` and `/captcha/:token`, where a single-use token from an email is the whole credential. Routes validate with zod and call services; services use tenant-scoped repos and, for the three producer cases, send a pg-boss job. Long-running work is never done in a request.
