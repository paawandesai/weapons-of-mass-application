Where data comes from, how it is transformed and where it lands, following one user from connected sources to a booked interview. The profile is built once from sources and frozen by approval; every later step reads the approved version. A daily run turns postings into judged candidates (kept 7 days for the run view) and a handful of selections. Each selection produces a resume PDF and a set of form answers, which the submission turns into an applied card with an activity trail. From then on mail drives the data: classification moves the status forward, a proposal becomes slots, a confirmation becomes an interview with a prep plan, an offer becomes pay data for the user. Every email the agent sends leaves a receipt row first.
