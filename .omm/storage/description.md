One Postgres 16 database holds four logically separate stores: the Drizzle-managed application tables, pg-boss's own schema, the envelope-encrypted vault and the transactional outbox. The only thing outside Postgres is the file store, a directory shared by api and worker through a compose volume. In production the `migrate` container runs `pnpm db:migrate` against the database before api and worker start. Demo tenants have two extra tables standing in for Gmail and Calendar.
