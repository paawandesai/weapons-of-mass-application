`packages/google/`: `oauth.ts` and `config.ts` for the sign-in flow, `client.ts` builds Drive, Gmail and Calendar clients from the vaulted refresh token (access tokens live in memory only) and recognises `invalid_grant` so a revoked connection is marked for reconnection, `send.ts` builds RFC 5322 MIME (text and HTML alternatives, inline images, attachments) and sends through Gmail.
