`packages/db/src/vault/`: envelope encryption. `master-key.ts` loads the master key from the environment (`assertVaultConfigured` runs at api and worker start); `cipher.ts` wraps a random per-tenant data key and seals each secret with AEAD, with tenant id, kind and ref as associated data so a row cannot be moved between tenants. Kinds: `google_refresh_token`, `ats_password`. Secrets are capped at 8 KiB; every access is logged to the activity log.
