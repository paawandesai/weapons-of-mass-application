`packages/llm/`: `client.ts` wraps `@anthropic-ai/sdk` (default model `claude-opus-5-5`, 32k max tokens, adaptive thinking, streaming, JSON-schema structured output derived from a zod schema in `schema.ts`, optional prompt caching of the system text, image inputs for CAPTCHA). `prompts.ts` loads versioned prompt files from `prompts/` (13 families: profile-build, extract-resume-facts, company-list, apply-decision, tailor-resume, classify-form-field, answer-form-question, solve-captcha-a and -b, inbox-link, inbox-classify, prep-plan, comparables-extract). `fake.ts` is the recorded-fixture client tests use.
