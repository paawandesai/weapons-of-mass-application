What exists and how the pieces relate. The product is an agent that runs a job search end to end: builds a profile from the user's connected accounts, finds postings, decides which to apply to, tailors a resume per posting, submits the application, handles recruiter email and books interviews only after the user confirms a time.

Three deployable processes share one pnpm workspace: a React single-page app (`apps/web`), a Hono HTTP API (`apps/api`) and a pg-boss worker (`apps/worker`). Everything stateful lives in one Postgres database: the application tables (Drizzle schema in `packages/db`), the pg-boss job queues, the encrypted credential vault and the follow-on-work outbox. Resume PDFs and CAPTCHA images live on a tenant-scoped file store directory. Five internal packages (`@wma/db`, `@wma/shared`, `@wma/llm`, `@wma/google`, `@wma/discovery`) hold what the processes share.
