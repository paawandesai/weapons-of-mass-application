`src/scheduling/`: `slots.ts` computes non-conflicting slots from the proposal and the calendar, `offer.ts` records the offer and emails the user single-use confirm links, `book.ts` (job `book-interview`) replies to the recruiter, creates the calendar event with the prep plan link, sets `interviewing`, and writes a `prep-plan` outbox row in the same transaction. `requeue.ts` re-offers unbooked interviews, `ports.ts` builds Calendar and mailbox ports per tenant. The reply is recorded before the event so a retry never re-sends it.
