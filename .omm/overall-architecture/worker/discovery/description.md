`src/discovery/`: the stateless daily run (`run.ts` `executeDailyRun`). Claims the `(user, date)` run row, resolves the company list (seeded only for demo tenants, else user companies plus the `company-list` prompt), sweeps the source adapters, drops postings that already have an application, judges at most `JUDGE_CAP_PER_RUN` candidates with `apply-decision@v1`, ranks by fit with deadline as tiebreaker and at most `MAX_PER_COMPANY_PER_RUN` per company, stores jobs and pending applications for the top N, and hands each to the submit queue.
