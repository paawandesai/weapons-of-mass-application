`src/profile/build.ts`, `bundle.ts`, `postvalidate.ts`, job in `src/jobs/profile-build.ts`. Bundles the connected sources (resume text, LinkedIn, GitHub, Drive documents through the vaulted Drive port), runs the `profile-build` and `extract-resume-facts` prompts, post-validates the document and stores a new profile version with the build marked done or failed. The user reviews and approves it in the web app.
