`apps/worker/`: one Node process that starts pg-boss, registers every job handler (`src/register.ts`), starts the pending-jobs dispatcher last, and in demo mode serves fixture ATS forms. Feature modules: `discovery/` (daily run), `submission/` (tailor, answer, fill, submit), `inbox/` (Gmail sync and classification), `scheduling/` (slot offers and booking), `notifications/` (digest, reminders), `prep/`, `negotiation/`, `profile/` (profile build), `demo/` (simulated recruiter, forms server, port factory). One shared Playwright browser per process.
