`src/routes/confirm.ts` and `captcha.ts`. The user arrives from an email holding a single-use token. `GET /confirm/:token` shows the slot, `POST` books it: `services/confirm.ts` marks the slot confirmed and sends `book-interview` and `schedule-reminders` to pg-boss with a `${interviewId}:${slotId}` singleton key; a second POST answers 410. `/captcha/:token` serves the image and records the human answer for the waiting submission.
