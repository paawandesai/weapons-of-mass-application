Sources: `POST /api/sources/resume` (PDF or DOCX parsed with pdf-parse and mammoth), `/linkedin` (public profile URL), `/github` (username, public repos), `GET /drive/folders` and `POST /drive` (folder ids), `DELETE /:kind`. Profile: `POST /build` enqueues `profile.build`, `GET /build/status` reads the pg-boss job state, `GET`/`PUT` the document, `POST /approve` records the approved version that unlocks every agent job. Survey: `GET`/`PUT /api/survey`.
