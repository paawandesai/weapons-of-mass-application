`apps/api/`: Hono app served by `@hono/node-server` on `PORT` (3000 in production). `src/app.ts` wires middleware and route groups; `src/main.ts` loads env, asserts the vault is configured, requires `SESSION_SECRET`, checks demo tenants and listens. Route modules under `src/routes/` are thin; `src/services/` holds the logic (board read model, profile builds, review gate, source fetchers, confirm and CAPTCHA token handling, the pg-boss producer).
