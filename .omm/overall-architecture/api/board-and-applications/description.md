`GET /api/board` is a read model over `applications` (`services/board.ts` `columnOf`): four columns, pending cards badged inside Applied. `GET /api/applications/:id` is the card detail with rationale, resume ref, form answers, threads, interviews and slot state, prep plan, feedback, offer data, CAPTCHA summary and cursor-paged activity. `POST /:id/stage` moves a card in one transaction with an optimistic `from` check (409 on mismatch), writes `stage_overrides` and an activity row. `GET /api/search/companies?q=` is the panic search (substring, max 20, min 2 chars).
